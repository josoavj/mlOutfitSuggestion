# Règles d'harmonie des couleurs

Voici les principes d'association des couleurs pour la composition des tenues de garde-robe :

## 1. Les couleurs neutres
Les couleurs suivantes sont considérées comme des neutres universels :
- noir
- blanc
- gris
- beige
- marron
- bleu_marine

Règle : Une couleur neutre peut être associée avec n'importe quelle autre couleur sans restriction.

## 2. Les paires harmonieuses et complémentaires (non-neutres)
Les associations suivantes entre couleurs vives ou spécifiques sont recommandées :
- bleu_marine avec rouge
- bleu_clair avec beige
- vert avec beige
- rose avec gris
- jaune avec bleu_marine
- violet avec gris

## 3. Le cas du multicolore
- multicolore : Les pièces multicolores ou à motifs très colorés doivent impérativement être associées uniquement avec des couleurs neutres pour éviter de surcharger la tenue visuellement.
